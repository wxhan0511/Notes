# FreeRTOS 软件定时器

led_timerHandle = osTimerNew(led_timer_callback, osTimerPeriodic, NULL, &led_timer_attributes);

osTimerOnce：只执行一次
osTimerPeriodic：周期性循环执行

<!-- 它是 FreeRTOS 软件定时器，运行在 Timer 守护任务（Timer Daemon Task） 里。Timer 守护任务 优先级默认最高,是一个专门处理定时器回调的任务,回调函数必须 快速执行、快速退出,不能阻塞、不能延时、不能死循环 -->
1）创建
c
运行
led_timerHandle = osTimerNew(led_timer_callback, osTimerPeriodic, NULL, &led_timer_attributes);
2）启动
c
运行
osTimerStart(led_timerHandle, 500);  // 500ms 周期
3）停止
c
运行
osTimerStop(led_timerHandle);
4）删除（几乎不用）
c
osTimerDelete(led_timerHandle);
c
